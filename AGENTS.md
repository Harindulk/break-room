# Working on Break Room

- Product spec: `SPEC.md`. Build exactly that; if something in it is unclear, pick the simplest reading and note it in the commit message.
- No dependencies, no build step. Plain ES modules served as static files.
- Run `node --test` before finishing a task; all tests must pass.
- Keep files small and readable; comment only the why.
- Never add secrets, tokens or analytics.
